🔑 Free Password Reset

💻 Computer par ye steps karein:
  1. Desktop par Sajjad-Academy-Password-Reset folder open karein.
  2. Folder ke andar address bar mein PowerShell likh kar Enter karein.
  3. Ye command chalayein:
    node reset-password.js
  4. Student ID mein neeche diya hua ID enter karein.
  5. New Password mein naya password enter karein.
  6. Jab Password successfully reset ho gaya! aaye, student ko naya password de dein.
  7. Student portal mein login karke 🔑 Change Password se apna permanent password bana sakta hai.
⚠️ Important: Ye free method aapke computer par local reset script use karta hai. serviceAccountKey.json ko kabhi GitHub par upload/share na karein.
