🔑 Free Password Reset

💻 Computer par ye steps karein:
  1. Desktop par Sajjad-Academy-Password-Reset folder open karein.
  2. Folder open karke keyboard se Ctrl + L press karein.
  3. Upar address bar select ho jayegi. Wahan powershell likhein aur Enter press karein.
  4. Ye command chalayein:
    node reset-password.js
  5. Student ID mein neeche diya hua ID enter karein.
  6. New Password mein naya password enter karein.
  7. Jab Password successfully reset ho gaya! aaye, student ko naya password de dein.
  8. Student portal mein login karke 🔑 Change Password se apna permanent password bana sakta hai.
⚠️ Important: Ye free method aapke computer par local reset script use karta hai. serviceAccountKey.json ko kabhi GitHub par upload/share na karein.
